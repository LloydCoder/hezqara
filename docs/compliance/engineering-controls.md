# Compliance engineering controls

HEZQARA applies least privilege, tenant isolation, audit controls, authentication, authorization, secure transport assumptions, secret management, data minimization and controlled external data flows. PHI should be transmitted to an AI/provider only when necessary for the specific workflow and under an approved data-processing/business-associate arrangement where applicable.

The platform is not represented as HIPAA/GDPR certified by virtue of these controls. Legal, organizational and contractual requirements remain part of deployment readiness.
