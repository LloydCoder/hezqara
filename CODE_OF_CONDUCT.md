# Contributor Covenant Code of Conduct

## Our Pledge

We are committed to making participation in HEZQARA respectful, professional, and free from harassment or discrimination. Contributors, maintainers, reviewers, and other participants are expected to act professionally and in good faith.

## Expected behavior

Examples of behavior that contribute to a positive environment include:

- being respectful and constructive in technical discussion;
- accepting and giving feedback professionally;
- focusing criticism on ideas, code, documentation, and decisions rather than people;
- respecting privacy and confidentiality;
- using inclusive and gender-neutral language;
- reporting security issues privately rather than exposing exploitable details publicly.

## Unacceptable behavior

Harassment, discrimination, threats, intimidation, personal attacks, doxxing, sexualized conduct, deliberate disruption, and publication of private or sensitive information are not acceptable.

## Enforcement

Project maintainers may remove or reject contributions and may restrict participation when this Code of Conduct is violated.

**Enforcement contact:** @LloydCoder via a private GitHub message. Do not include secrets or PHI in a report.

## Scope

This Code of Conduct applies to repository issues, pull requests, code review, project discussions, documentation, and other project spaces operated by the maintainers.
